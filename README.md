# 🔐 ECC-Based Multi-Factor Authentication System

## 📌 Overview

This project is developed as a **Capstone Team Project**, focusing on building a **secure Multi-Factor Authentication (MFA) system** using **Elliptic Curve Cryptography (ECC)**.

It combines:

* Password-based authentication
* Email verification
* ECC-based cryptographic verification

---

## 🎓 Capstone Project

This project was developed as part of our **final year capstone** as a **team project**.

---

## 🚀 Features

* 🔑 Secure login system
* 📧 Email-based OTP verification
* 🔐 ECC-based key generation & validation
* 📊 User dashboard with security logs
* ⚡ Fast and lightweight authentication flow
* 🛡️ Enhanced protection against brute-force attacks

---

## 🧠 Tech Stack

* **Frontend:** React (Vite + TypeScript)
* **UI:** Tailwind CSS + ShadCN UI
* **Backend/Services:** Supabase
* **Security:** Elliptic Curve Cryptography (ECC)

---

## 🔐 How ECC is Used

* Generates public/private key pairs
* Encrypts sensitive authentication data
* Ensures secure verification during login
* Provides strong security with lower computational cost

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```
git clone https://github.com/ATMAKURU-PRAKASH/ECC-Based-MFA.git
cd ECC-Based-MFA
```

### 2️⃣ Install dependencies

```
npm install
```

### 3️⃣ Run the project

```
npm run dev
```

---

## 🌐 Environment Variables

Create a `.env` file and add:

```
VITE_SUPABASE_URL=your_url
VITE_SUPABASE_ANON_KEY=your_key
```
